# Interface typography

Open-source fonts served locally:
- Bricolage Grotesque: regular 400 and display 800 (Google Fonts).
- Noto Sans SC: 400, 700 and 900. Subset of login UI characters; other characters use system fallback.

Font files are TrueType. Corresponding SIL Open Font Licenses are included.
Reference-site proprietary fonts are not included.

- Noto Sans SC variable 100–900: `learning-chinese.woff2`, subset covering the 1,075 non-ASCII characters in the frontend sources. Learner UI uses this local font; user-generated content outside the subset uses system fallback. Same Noto SIL Open Font License.
