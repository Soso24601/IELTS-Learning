# 本机快速提取音轨原型

目的：当 Zeabur 不能访问 YouTube、且视频没有字幕时，在用户电脑上获取完整音轨，随后沿用网站现有的“上传音频 → 百炼识别 → 导入当前视频文字稿”流程。获取过程按下载速度进行，不要求按视频时长播放。

这个原型参考 [substrata](https://github.com/jmviz/substrata) 的本机辅助程序思路。它目前不是 Chrome 插件，也没有通过完整浏览器验收；页面按钮标有“实验”。

## 在 macOS 上试用

1. 下载或克隆整个项目；电脑需要 Python 3.10+、Node.js、Chrome，以及能够访问 YouTube。
2. 双击 `tools/start-local-youtube-bridge.command`。它会从 yt-dlp 官方 GitHub 发布页下载 2026.08.19 版本，并校验 SHA-256；首次启动可能花几分钟。保持打开的终端窗口不关闭。
3. 在 `https://ielts.grincaq.info` 登录，打开 YouTube 视频材料的字幕面板，点击“本机快速提取音轨并识别（实验）”。
4. 音轨会临时保存在本机，随后由网页上传到已登录的站点，百炼识别后导入原视频材料。完成后本机临时文件会删除。

本机助手只监听 `127.0.0.1:18765`，只接受站点和本地开发地址的来源，且只接受 11 位 YouTube 视频 ID。音轨最长 3 小时、最大 200 MB。为了降低长视频上传量，会优先选择不超过约 80 kbps 的音频流。

## 当前验证

- 官方 yt-dlp 2026.08.19 发布文件的 SHA-256 校验通过。
- 对测试视频 `h2ou2A_-8JU`，本机在数秒内读到 7568 秒视频的音轨信息，音频格式包含 WebM；音轨实际读取 65536 字节，HTTP 206。原型未下载全部音轨，也未使用用户百炼 Key 发起付费识别。
- 本机辅助程序对公开短视频 `jNQXAC9IVRw` 完成实际下载，得到 143795 字节 WebM 音轨；随后清理了测试文件。
- 本机浏览器从 `http://localhost:3000` 成功跨域读取 `http://127.0.0.1:18765/health`；HTTPS 正式站点到本机的访问权限仍待实际验收。
- 本机可获得的旧版 yt-dlp 无法解析该视频，因此安装脚本改为获取并校验官方新版。
- 待验收：Chrome 从 HTTPS 站点访问本机助手的权限提示、长视频完整音轨下载、200 MB 上传与百炼返回结果。未完成这些验收前，不应将该路径当成稳定功能。
