# YouTube 视频语音识别

使用「视频」材料保存 YouTube 链接，然后点击「识别 YouTube 视频语音（百炼）」。无需改成音频材料，也不依赖视频是否有官方字幕。识别结果写入原材料，保留视频链接、类型和笔记。

## 处理过程

1. 验证 YouTube 主机和视频 ID，将链接规范化为单个视频地址。
2. 在后台用 yt-dlp 获取独立音轨；不读取用户浏览器 Cookie。
3. 百炼通过随机临时地址读取音轨，返回英文字幕和句子时间戳。
4. 已配置的文本模型提供中文翻译。翻译失败或耗时过长时保留英文和时间轴。
5. 完成或失败后移除临时音轨和下载目录。

## 部署与限制

- Dockerfile 安装 Python、固定版本 yt-dlp 2026.8.19 和 yt-dlp-ejs 0.8.0；Node 24 运行 YouTube 的脚本解析。
- 在网站「账号与设置 → 语音识别」配置百炼 Key，地域必须匹配。
- 使用公开 HTTPS 网站地址；百炼需要读取网站上的临时音频。
- 单条视频最长 3 小时、音轨最大 200 MB，不接受直播。
- 后台任务当前保存在单个服务进程的内存中：保持单副本，处理中不要重新部署，并保持页面打开。完成结果供页面获取 10 分钟。
- 云服务器可能遭遇 YouTube 的访问限制。此时提示明确原因，可在同一视频字幕面板上传对应音频，保留 YouTube 链接。不能保证所有视频可获取。
