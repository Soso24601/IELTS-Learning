# IELTS YouTube 字幕导入助手（原型）

Chrome Manifest V3 扩展：从用户当前打开的 YouTube 文字稿面板读取已有字幕和时间戳，滚动面板收集完整条目，复制成学习网页可识别的 `[开始秒-结束秒] 英文字幕` 格式。

扩展仅在用户点击按钮后通过 `activeTab` 和 `scripting` 访问当前标签页；字幕在浏览器本地读取并写入剪贴板，不上传到服务器。

## 安装测试

1. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择 `extension/youtube-transcript-copier` 文件夹。
3. 打开一个有字幕的 YouTube 视频，在视频菜单里先选择「显示文字稿」。
4. 点击扩展图标，再点「提取并复制字幕」。
5. 回到 IELTS 学习网页的字幕编辑框粘贴，然后使用 AI 自动断句。

## 当前边界

- 读取 YouTube 页面已经提供的字幕，不做服务器抓取。
- 视频没有任何字幕轨道时会明确提示；本原型不捕获或上传音频，也不做语音识别。
- YouTube 会调整页面 DOM，文字稿面板的结构变化时需要更新选择器。
